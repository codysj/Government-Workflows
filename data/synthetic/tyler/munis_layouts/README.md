# Munis export layouts (synthetic data)

**All data here is synthetic** (the same fictional City of Riverbend as the
parent folder). What is real is the *layout*: column headers, value formats,
title blocks, totals, and footers as they appear in public Munis output (see
[`docs/tyler_assumptions.md`](../../../../docs/tyler_assumptions.md) section 0 for
sources). `tests/integration/test_munis_layouts.py` runs the workflows on them.

| File | Munis source | Confirmed from public output | Inferred |
| --- | --- | --- | --- |
| `ap_invoice_central.csv` | Invoice Central, Excel export | All 21 column names, in order; `.00` zero amounts; one date written as an Excel serial number (a known export defect) | That "Vendor" holds the vendor number only (it may hold number and name; both are handled); numeric vendor numbers |
| `vendor_list.csv` | (none found) | — | No flat vendor-master export was found; this is the parent folder's layout with numeric vendor numbers |
| `cash_disbursements_journal.csv` | A/P Cash Disbursements Journal (`apcshdsb`) | Columns `CHECK NO, CHK DATE, TYPE, VENDOR NAME, VOUCHER, INVOICE, INV DATE, PO, WARRANT #, NET`; `PRTD`/`VOID` types; void shown negative; vendor number printed before the name; check totals, `*** CASH ACCOUNT TOTAL ***`, `*** GRAND TOTAL ***`; footer lines `Report generated:`, `Program ID:`, `** END OF REPORT - Generated by ... **` | That a CSV/Excel export keeps the printed layout (the public copies are PDFs) |
| `ytd_budget_report.csv` | Year-to-Date Budget Report (`glytdbud`) | Amount columns `ORIGINAL APPROP, TRANFRS/ADJSTMTS, REVISED BUDGET, YTD EXPENDED, ENCUMBRANCES, AVAILABLE BUDGET, PCT USED`; title block; revenue in credit sign (negative); `TOTAL <org>` and `GRAND TOTAL` lines; `.0%`; the footer | Separate `Fund`, `Org`, `Object`, `Account Description` columns (the printed report shows the account on one line; Account Inquiry's Excel export has these fields) |

Generated once from the parent folder's CSVs by re-shaping rows (same planted
anomalies), so the AP review finds the same 13 issues as on the canonical
sample, and the budget review the same 4 variances plus the revenue shortfall.
